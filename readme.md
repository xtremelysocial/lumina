=== Lumina ===

== Description ==
Lumina is a high-end evolution of the flat design aesthetic to a modern "Post Flat" era. Moving beyond the limitations of "flat" layouts, Lumina introduces a philosophy centered on luminapheric depth, light and interactive physics. 

Built on a foundation of earthy notes and ambient lighting, the theme utilizes sophisticated color-scheme variations to provide a rich set of color palettes to create a focused, high-contrast environment. With a signature 'card-like' layout, Lumina containerizes content within high-radius surfaces—evoking the premium feel of modern tech—while maintaining sharp, immersive horizon lines for cinematic hero sections.

Lumina is a Child Theme of Flat Blocks but with a completely different color palette, styles, and block patterns while adding automatic object-sensing and animation.

For more information go to [http://xtremelysocial.com/wordpress/lumina/]. 

== Installation ==

1. Download and install the parent theme Flat Blocks
2. Download and install this Lumina child theme
3. Activate this child theme through the 'Appearance' menu in WordPress
4. Read the notes below about how to use this child theme

== How to Use This Child Theme ==

This theme is a standard WordPress "child theme" of Flat Blocks. While you could make edits to it, it is strongly recommended that you create a copy of it in a new directory and update the theme name in style.css. 

The easiest way to do that is to use the [Create Block Theme](https://wordpress.org/plugins/create-block-theme/) plugin.

Install the Create Child Theme plugin 
Use the Full Site Editor to adjust any global styles, templates, template parts, etc. to your liking.
Use the Create Child Theme plugin to export a new child theme based on this one.

You can read more information about how to use child themes on WordPress.org [https://codex.wordpress.org/Child_Themes]
